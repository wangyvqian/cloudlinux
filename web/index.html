「一键准备」会依次：安装 QEMU → 下载镜像（支持断点续传与 SHA256 校验）→ 准备磁盘 → 写入配置。
ISO 会建空盘并从光盘引导安装；云镜像（.qcow2 / .img）免安装—— 助手会以它作后端做一层 qcow2 叠加层直接用，原镜像保持只读，想重置删掉叠加层即可。

自定义镜像链接（其他发行版）

其他发行版请自己找镜像地址（各发行版官网 / 镜像站均可）。 填了官方 SHA256 就会校验；不填则默认不校验，请自行确认来源可信。
小技巧：很多发行版提供云镜像（Ubuntu cloud image、Debian genericcloud 等， 后缀 .img / .qcow2），体积更小、下完直接能跑，不用装系统。
